# AI Resume Analyzer

An AI-powered resume analyzer built using Python, Streamlit, and Groq API.

## Features
- Resume PDF upload
- ATS score analysis
- Skills extraction
- Missing skills detection
- Resume improvement suggestions
- Suitable job role recommendations

## Technologies Used
- Python
- Streamlit
- Groq API
- pdfplumber

## How to Run

1. Install dependencies

pip install -r requirements.txt

2. Run the app

streamlit run app.py
